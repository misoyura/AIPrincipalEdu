02나만의 맞춤형 비서, 구글 젬스(Gems)

Gem은 내 업무 방식을 기억하는 나만의 비서입니다.

매번 설명하기

역할을 다시 알려 준다

검토 기준을 다시 적는다

양식을 다시 정한다

한 번 정해 두기: Gem

역할, 기준, 양식을 저장

파일만 올리면 바로 검토

언제 써도 같은 기준

구글 젬스(Gems)란?

  • 사용자가 원하는 역할과 지식을 담아 만든 맞춤형 AI
  • 반복 업무를 효율적으로 자동화하는 나만의 AI 비서
  • 코딩 없이 누구나 쉽게 제작하고 공유하는 생산성 도구

활용 분야 — 학습: 개인 수준별 1:1 맞춤형 학습 튜터 · 건강: 나만의 식단·운동 전담 헬스 코치 · 홍보: 타깃 맞춤형 SNS 콘텐츠 제작자 · 행정: 격식과 규격을 갖춘 공문·보도자료 에디터 · 소통: 상황별 비즈니스 이메일 작성 비서

Gem 만들기 핵심 구성 요소

  1. 이름 (Name)Gem의 역할과 목적이 한눈에 드러나도록 짧고 명확하게 작성합니다.
  2. 설명 (Description)이 Gem이 무엇을 도와주는 도구인지 1~2문장으로 간단히 소개합니다.
  3. 요청 사항 (Gem의 행동 지침 / 역할 지시)어떤 말투와 형식으로 작성해야 하는지 AI의 행동 규칙을 명확하게 지시합니다.
  4. 지식 (Knowledge 업로드)참고해야 할 학교 양식, 업무 규정, 예시 문서 등을 업로드하는 곳입니다.

지침문 · 결재 검토 비서

💡 사용법Gem 만들기 화면의 이름 · 설명 · 요청 사항 칸에 아래 세 박스를 각각 복사해 붙여넣으세요.
결재 검토 비서
교직원이 올린 계획서·기안문과 접수된 공문을 결재 전에 검토해, 빠진 항목과 확인할 질문, 우리 학교가 해야 할 일을 표로 정리해 주는 교장 전용 비서입니다.
검토 결과는 PDF 파일로 바로 내려받을 수 있습니다.
[역할]
너는 학교장의 결재 문서 검토를 돕는 비서야. 교직원이 올린 계획서, 기안문, 접수된 공문을 결재 전에 검토해.

[검토 순서 - 계획서·기안문]
① 문서의 목적과 핵심 내용을 세 줄로 요약해.
② 빠진 항목을 찾아. 예산, 안전, 일정, 담당자, 비상 대책(우천·응급 상황 등), 개인정보 처리를 꼭 살펴봐.
③ 날짜와 요일, 금액 계산, 합계가 맞는지 확인해.
④ 누가, 언제, 무엇을 하는지 분명하지 않은 표현을 찾아 그대로 인용해.
⑤ 결재 전에 담당 교사에게 물어볼 질문을 3~5개 만들어.
⑥ 결재 의견을 한 줄로 써. '승인 가능 / 보완 후 승인 / 재검토' 중 하나로 시작해.

[검토 순서 - 공문]
① 공문의 요지를 세 줄로 요약해.
② 제출 기한과 주요 날짜를 정리하고, 본문과 붙임의 날짜가 서로 맞는지 확인해.
③ 우리 학교가 해야 할 일을 목록으로 정리해.
④ 담당 부서나 담당자를 정해야 할 일, 예산이 필요한 일, 학교장 확인이 필요한 일을 따로 표시해.

[출력 양식]
- 검토 결과를 표로 정리해. 표의 열은 '항목 | 검토 내용 | 근거(문서 위치)'로 해.
- 표 아래에 담당 교사에게 그대로 전달할 수 있는 보완 요청 문장을 2~3줄로 덧붙여.

[PDF로 받기]
- 검토 결과는 대화창이 아니라 캔버스 문서로 작성해.
- 문서 맨 위에 제목 '결재 검토 의견서'와 검토한 문서 이름, 검토일을 적어.
- 문서 구성은 '1. 핵심 요약 → 2. 검토 결과 표 → 3. 담당자에게 확인할 질문 → 4. 결재 의견 → 5. 보완 요청 문장' 순서로 해.
- 인쇄했을 때 A4 한두 쪽에 들어가도록 간결하게 써
- 문서를 다 쓴 뒤, 캔버스에서 PDF로 바로 내려받을 수 있다고 한 줄로 안내해.

[말투]
- 간결한 개조식으로 써.
- 담당 교사의 수고를 존중하는 표현을 쓰고, 지적보다 보완 제안의 말투로 써.

[금지사항]
- 문서에 없는 날짜, 수치, 규정을 지어내지 마. 근거를 찾을 수 없으면 '확인 필요'로 표시해.
- 법령이나 지침 조항을 추측해서 인용하지 마.
- 학생, 학부모, 교직원의 이름과 연락처 등 개인정보는 결과에 다시 적지 마.

[참고 자료]
- 지식에 올린 파일이 있으면 그 기준에 비춰 판단하고, 어떤 자료를 근거로 했는지 밝혀 줘.
- 여러 문서가 함께 있으면 문서끼리 날짜와 내용이 맞는지도 확인해.
- 문서를 첨부하지 않고 요청하면, 검토할 문서를 첨부해 달라고 먼저 요청해.

제미나이 캔버스 도구로 나만의 웹/앱을 만듭니다. 한 번에 다 만들지 않고, 탭 하나부터.

2
입력 항목고를 것과 쓸 것을 목록으로
3

1단계 · 뼈대와 훈화 생성기

교장선생님들이 쓰는 "교장실 AI 비서" 웹앱을 만들어줘.
1단계로 뼈대와 첫 번째 탭만 만들어줘.

[전체 화면]
- 탭 3개: 훈화·인사말 / 민원 응대 연습 / 가정통신문
- 첫 번째 탭만 작동, 나머지는 "준비 중"으로 표시
- 상단에 개인정보 입력 금지 안내 문구

[훈화·인사말 탭]
- 왼쪽 입력, 오른쪽 결과 (휴대폰에서는 1단)
- 입력: 행사, 시기·계절, 학교 특색 키워드,
  길이(1·3·5분), 분위기 4가지, 듣는 사람
- [원고 만들기]를 누르면 Gemini API로 원고 생성
- 결과 아래 [복사하기] [다시 생성] 버튼
- 생성 중에는 "원고를 쓰고 있습니다..." 표시
✍ 실습 (3분) — 1단계 결과: 훈화·인사말 생성기 1. 우리 학교의 다음 행사를 고릅니다  2. 학교 특색 키워드를 2~3개 넣습니다  3. 분위기를 바꿔 가며 두 번 생성합니다  4. 마음에 드는 문장을 골라 봅니다
→ 같은 입력, 다른 분위기로 결과를 비교해 보세요.

2단계 · 앱 속 AI에게 주는 지시문 다듬기

교장선생님(행사·분위기를 입력) → 웹앱(숨은 지시문을 덧붙임) → Gemini(원고 작성)

훈화 원고를 만들 때 AI에게 보내는 지시문을 아래처럼 바꿔줘.
"당신은 경험 많은 한국 학교 교장의 연설문 작가입니다.
 조건: 청중을 부르는 인사로 시작, 계절 장면 하나,
 학교 키워드를 자연스럽게, 듣는 사람 눈높이의 쉬운 말,
 짧은 당부와 감사로 마무리. 본문만 쓰고 마크다운 기호 금지,
 실제 사람 이름을 지어내지 말 것."
길이: 1분 300자 / 3분 900자 / 5분 1,500자 (공백 제외)
결과 위에 "글자 수 · 낭독 약 ○분 예상"을 표시해줘
무엇이 달라지나효과

금지 사항이름·기호 실수 줄임

지시문 다듬기 전 (예시)

학생 여러분 안녕하십니까. 오늘은 학예회 날입니다. 학예회는 여러분이 그동안 열심히 준비한 것을 보여 주는 소중한 자리입니다. 모두 최선을 다해 주시기 바랍니다. 또한 학부모님께서도 바쁘신 가운데 와 주셔서 감사합니다. 오늘 하루 즐거운 시간 되시기 바랍니다.

▶ 누구에게나 할 수 있는 말, 장면이 없음

지시문 다듬은 후 (예시)

사랑하는 우리 학생 여러분, 그리고 귀한 걸음 해 주신 학부모님, 반갑습니다. 운동장 가 은행나무가 하루가 다르게 노랗게 물들고 있습니다. 지난 몇 주 동안 쉬는 시간마다 복도 끝에서 들려오던 리코더 소리, 텃밭 옆 그늘에서 대사를 맞춰 보던 목소리를 교장선생님은 다 듣고 있었습니다.

▶ 계절 장면 + 우리 학교 이야기 + 청중 호명

✓ 핵심구체적으로 요청하면 결과가 달라집니다.

3단계 ① · 민원 응대 연습 만들기

이제 두 번째 탭 "민원 응대 연습"을 만들어줘.

[입력]
- 상황: 학교폭력 처리 불만, 담임 교체 요구, 급식 불만,
  수행평가 이의, 체험학습 안전, 직접 입력
- 학부모 성향: 화가 난 / 끈질긴 / 논리적인 / 불안한
- 버튼: [새 상담 시작] [상담 종료 · 피드백 받기]

[대화 화면]
- 학부모는 왼쪽 흰 말풍선, 교장은 오른쪽 남색 말풍선
- 시작하면 AI가 학부모로서 먼저 말을 건다

[피드백]
- 공감 표현 / 사실 확인 / 절차·기한 안내 (각 5점)
- 잘한 점, 고쳐 쓸 문장(원래 → 이렇게), 한 줄 조언
AI에게 역할 맡기기내용
역할선택한 상황의 학부모, 한 번에 2~4문장으로 말하기
반응 규칙공감하고 기한을 말하면 누그러지고, 회피하면 더 강하게 반응
지킬 선욕설·인신공격은 하지 않기, 이름 대신 "우리 아이"로 부르기

3단계 ② · 응대 가이드 흐름

  1. ① 학부모 말AI가 학부모 역할
  2. ② 응대 가이드챙길 점 3 + 추천 답변
  3. ③ 교장 답변참고해서 내 말로
  4. ④ 반복상담이 끝날 때까지
  5. ⑤ 피드백항목별 점수

가이드 상자 구성 — 꼭 챙길 점 3가지 · 추천 답변 예시 2~3문장 (공감 → 사실 확인 → 절차·기한) · [입력창에 넣고 고치기] 버튼 · [가이드 다시 받기] 버튼 · 체크박스로 켜고 끄기

3단계 ③ · 응대 가이드 프롬프트

[응대 가이드 기능 추가]
- 학부모 말이 끝날 때마다, 교장이 답하기 전에
  대화창 아래에 "응대 가이드" 상자를 보여줘
- 내용: 꼭 챙길 행동 3가지 (각 25자 안팎)
  + 추천 답변 2~3문장 (공감 → 사실 확인 → 절차·기한)
- 상황, 학부모 성향, 지금까지의 대화 전체를 함께 보낼 것
- 버튼: [입력창에 넣고 고치기] [가이드 다시 받기]
- 교장이 답을 보내면 숨기고, 다음 학부모 말에 새 가이드
- "응대 가이드 보기" 체크박스로 켜고 끄기
- 초록색 점선 테두리로 말풍선과 구분
- 지킬 수 없는 약속이나 법적 판단은 넣지 말 것

04학교 경영 대시보드

학교 교육계획서를 올리면 실시간 운영 현황 대시보드를 만들어 주는 웹앱을 캔버스로 만듭니다.

학교 교육계획서를 올리면 내용을 정밀 분석하여 실시간 운영 현황 대시보드를 생성해 주는 웹앱 「학교 경영 대시보드」를 만들어 줘.

[핵심 수정 및 파일 업로드 요구사항 - 필수]
1. PDF 파일 지원: cdnjs의 PDF.js 라이브러리(pdf.min.js 및 pdf.worker.min.js)를 반드시 연동할 것.
2. 자동 텍스트 추출: [계획서 올리기] 영역에 .pdf 파일이나 .txt, .md 파일을 드래그 앤 드롭하거나 선택하면, 바이너리 깨짐 없이 한글 텍스트를 파싱하여 "내용 직접 붙여넣기" 칸에 자동 입력할 것. (추출 중 로딩 스피너 및 진행 상태 메시지 표시)
3. 안정적인 분석 체계:
   - Gemini API 호출 시 응답 마크다운 태그 정제 및 JSON 스키마를 철저히 검증할 것.
   - API 통신 지연, 쿼터 제한 또는 인증 오류가 발생해도 중단되지 않도록, 문서 구조(비전·과제·부서·시기·예산)를 분석하는 자체 내장 엔진(Fallback)을 함께 구현하여 무조건 정상 렌더링되도록 처리할 것.

[기본 화면 구성 (입력 뷰)]
- 상단 배너: 솔루션 소개 및 데이터 원칙 가이드.

  - 진행 상태 선택 셀렉트(계획, 진행 중, 완료, 주의).
- 예산 사업 편성 및 검토 현황:
  - 총 예산 합계액 및 확인 필요 사업 건수 통계 요약 배지.
  - 사업명, 담당 부서, 사업비, 추진 시기, 비고가 포함된 반응형 테이블.

06이미지 생성 — 제미나이 나노바나나 2.1 · GPT Image 2.1

안내 포스터 (제미나이 나노바나나 2.1)

학교 교무실 출입 금지를 안내하는 유머러스한 세로형 포스터, 비율 2:3.
흰색 배경 중앙에 두 명의 여성 교사가 나란히 서 있는 전신 일러스트. 두 사람 모두 검은 머리를 머리 위로 둥글게 묶고, 넉넉한 흰색 상의와 회색 와이드 팬츠, 운동화를 착용한다.
왼쪽 인물은 흰색 집업 재킷을 입고 한쪽 팔을 굽혀 주먹을 올리며, 다른 팔은 옆으로 뻗는다.
오른쪽 인물은 흰색 후드티를 입고 한쪽 팔을 굽히고 다른 팔은 오른쪽으로 길게 뻗는다.
두 사람 모두 무심하고 살짝 엄격한 표정으로 코믹한 춤 동작을 취한다.
굵고 약간 불규칙한 검정 외곽선으로 그린 간결한 손그림 만화 스타일. 눈은 작은 검정 점이나 짧은 선, 코와 입은 최소한의 선으로 표현한다. 머리카락은 검정 단색, 옷은 흰색과 회색 단색으로 채운다.
명암, 그라데이션, 입체감, 복잡한 배경 없이 평면적으로 표현한다. 넉넉한 여백과 친근한 학교 게시물 분위기.
상단에는 자연스러운 한글 손글씨로 두 줄의 대화를 배치한다.
첫째 줄: “얘들아 얘들아”는 검정색, “왜요 쌤 왜요쌤”은 회색.
둘째 줄: “교무실 들어올땐 노크 꼭 하랬지”는 검정색, “죄송해요 쌤”은 회색.
하단에는 매우 크고 굵은 검정 고딕체로 다음 문구를 두 줄로 배치한다.
“시험문제 출제기간”
“교무실 출입금지”
글자가 잘리지 않도록 배치하고, 하단 문구는 멀리서도 읽을 수 있게 강조한다. 로고와 워터마크는 제외한다.
