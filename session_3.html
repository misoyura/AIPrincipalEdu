웹 버전과 데스크톱 앱의 차이, 기초 용어, 사용량을 아끼는 법을 먼저 알아 둡니다.

Claude 웹 버전 vs 데스크톱 앱 비교

구분웹 버전 (Web)데스크톱 앱 (Windows)
토큰 소모일반 채팅 — 토큰 소모량 동일, 동일한 Anthropic 서버 사용일반 채팅 — 토큰 소모량 동일 (차이 없음)
접근성 / 성능브라우저만 있으면 어디서나 사용 가능, 설치 불필요OS와 더 긴밀하게 통합되어 반응 속도 향상, 멀티태스킹 및 단축키 사용 편리
파일/프로젝트 작업파일을 직접 업로드하여 공유 (매번 업로드 필요)Claude Code (획기적인 절약) — 로컬 파일 직접 접근, 코드 실행, 프로젝트 폴더 연결. 전체 데이터를 보내지 않고 ‘결과’만 주고받아 토큰을 최대 90% 이상 절약 가능
사용 환경멀티 디바이스 — 인터넷만 되면 어떤 기기에서든 동기화하여 사용 가능로컬 환경 최적화 — 로컬 파일 접근, 클립보드/파일 드래그 앤 드롭, 백그라운드 실행 등
추천 대상가벼운 채팅, 짧은 질문, 아이디어 브레인스토밍, 파일 작업이 거의 없는 사용자개발자, 데이터 분석가, 연구자, 대용량 문서/코드 작업 등 로컬 파일 기반 업무 사용자
💡 토큰을 아끼는 공통 팁 새 대화 자주 시작하기 — 대화가 길어질수록 컨텍스트가 커져 토큰 소모가 기하급수적으로 증가합니다.
이미지 업로드 주의 — 이미지 1장당 약 1,200~1,600 토큰. 불필요한 이미지는 최소화하세요.
긴 PDF 주의 — 긴 PDF는 수만 개의 토큰을 한 번에 사용. 필요한 부분만 텍스트로 추출하세요.
불필요한 맥락 줄이기 — 필요한 정보만 간결하게 제공하고, 중복된 설명은 줄이는 것이 효율적입니다.

클로드 사용량 아끼는 3가지

필요한 내용만 정확히 주면, 더 빠르고 더 좋은 답을 얻을 수 있어요.

1
한 번에 모아서 요청하기원하는 조건을 한 메시지에 모두 적어요. (뮤직비디오 프롬프트처럼)
주제 · 분량 · 스타일 · 형식 · 예시 · 추가 조건
2
주제가 바뀌면 새 채팅대화가 길어질수록 AI가 읽어야 할 앞 내용이 많아져요.
3
보내기 전에 한 번 읽기고칠 내용이 줄면 주고받는 횟수도 줄어요.
오탈자 확인 · 조건 누락 확인 · 불필요한 내용 제거

이어서 Claude 로그인 → 화면 구성과 모델 설정 → 설정 - 개인정보보호 순서로 화면을 함께 확인합니다.

02아티팩트 — 훈화 / 인사말 도우미 앱 제작

아티팩트는 클로드가 만든 결과물(문서·웹페이지·다이어그램·작은 도구 등)을 대화창 옆 별도 창에 완성본으로 띄워 주는 기능입니다.

실습 · 교장 훈화·인사말 도우미 웹앱

교장선생님이 학교 행사나 상황에 맞는 훈화·인사말 초안을 쉽게 작성할 수 있는 웹앱을 만들어줘.

앱 이름
교장 훈화·인사말 도우미

주요 사용자
중·고등학교 교장 및 학교 관리자

입력 항목
- 학교명
- 인사말 종류: 조회 훈화 / 입학식 / 졸업식 / 개학식 / 종업식 / 학부모 행사 / 교직원 회의 / 학교 행사 / 기타
- 대상: 학생 / 학부모 / 교직원 / 전체
- 핵심 주제 또는 전달하고 싶은 내용
- 말하기 시간: 1분 / 3분 / 5분
- 분위기: 따뜻하게 / 격려하는 / 진중하게 / 친근하게

기능
[인사말 만들기] 버튼을 누르면 입력한 내용을 바탕으로 훈화 또는 인사말 초안을 만들어줘.
결과 화면에는
- 제목
- 인사말 본문
- [워드로 다운로드]
- [다시 작성하기]
버튼을 만들어줘.
[워드로 다운로드]를 누르면 제목과 본문이 담긴 워드 파일(.docx)이 "학교명_인사말종류.docx" 이름으로 저장되게 해줘.
워드 파일은 맑은 고딕, 제목 16pt 굵게, 본문 12pt, 줄간격 1.6으로 해줘.
사용자가 입력하지 않은 학교 정보, 실제 사건, 통계, 학생 사례 등은 임의로 만들어내지 않도록 해줘.

디자인
교장선생님이 처음 사용해도 바로 이해할 수 있도록 단순하고 깔끔하게 만들어줘.
큰 글씨와 명확한 버튼을 사용하고 PC와 스마트폰 모두에서 편하게 사용할 수 있게 해줘.

먼저 기본 기능이 작동하는 웹앱을 완성하고 실행해서 확인할 수 있게 해줘.
